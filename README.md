## Structure

├── RunningBunny/
│ └── index.html # RunningBunny privacy policy
├── index.html # Landing page linking to all policies
└── README.md

Each app gets its own subfolder so policy URLs stay stable even as more apps are added.

## Updating a policy

1. Edit the relevant `index.html` (or `.md`) file under the app's folder.
2. Commit and push to `main`.
3. GitHub Pages redeploys automatically — changes are live within a minute or two.
